# 蓮子の眼

宇佐見蓮子の「星を見ただけで今の時間が分かり、月を見ただけで今居る場所が分かる程度の能力」を体験する Web アプリ（試用版）．

**▶ https://kyoto-shirayui.github.io/renko-eyes/**

- スマホ（iPhone は Safari，Android は Chrome）で開き，空にかざして遊ぶ
- 使い方：[manual.html](https://kyoto-shirayui.github.io/renko-eyes/manual.html)
- 出典・参考文献：[credits.html](https://kyoto-shirayui.github.io/renko-eyes/credits.html)
- 一度開くと端末に保存され，通信が無くても動く
- 位置情報・カメラ・マイクは使わず，何も送信しない
